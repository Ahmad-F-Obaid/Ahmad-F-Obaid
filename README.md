### 🚀 Featured Projects

#### 🩺 [OCTDL Eye Disease Classification](https://github.com/Ahmad-F-Obaid/OCTDL-Eye-Disease-Classification)
A medical imaging classifier comparing ResNet50 and InceptionV3 for diagnosing 7 retinal conditions (AMD, DME, ERM, Normal, RAO, RVO, VID) from Optical Coherence Tomography scans, using transfer learning with a two-phase, frozen-then-fine-tuned training strategy.
**Results:** ResNet50 reached 94.2% accuracy / 93.9% F1 (best class 98.5%), outperforming InceptionV3 at 92.7% / 92.4%. Wrapped in a Gradio app with confidence visualizations and side-by-side model comparison.
**Tech:** Python, TensorFlow/Keras, ResNet50, InceptionV3, Gradio

#### 🏷️ [NLP – NER System](https://github.com/Ahmad-F-Obaid/NLP---NER-System)
A Named Entity Recognition system for detecting person names, built on a Maximum Entropy Markov Model rather than a pretrained transformer — over 50 hand-engineered features across 11 categories (orthographic patterns, gazetteers, contextual windows, transition features) plus dedicated class-imbalance handling.
**Results:** 92.51% precision and 79.63% F1.
**Tech:** Java, MEMM, custom feature engineering

#### 📝 [Automatic Essay Grading System](https://github.com/Ahmad-F-Obaid/Automatic-Essay-Grading-System)
An AI essay grader built on Mistral-7B-Instruct, fine-tuned with LoRA to score essays on a 0–4 scale with written feedback and benchmarked against the base model. Ships with a 5-tab Gradio app for single grading, model comparison, batch processing, analytics, and a Science QA mode.
**Results:** 15–30% more accurate than the un-tuned baseline (MAE/RMSE/correlation/exact-match metrics), with fine-tuning completing in ~25 minutes on a single T4 GPU.
**Tech:** PyTorch, Transformers, Unsloth, Gradio

#### 🐦 [Twitter Stream Processing Pipeline](https://github.com/Ahmad-F-Obaid/Twitter-Stream-Processing-Pipeline)
A real-time big-data pipeline built as a team project for An-Najah National University's Big Data Engineering & Information Retrieval course. Streams ~18,800 historical tweets through Kafka into Spark Structured Streaming, runs Bloom-filter deduplication and Spark NLP sentiment analysis, then indexes everything into OpenSearch behind an interactive Streamlit dashboard (full-text + faceted search, geospatial map, sentiment/trend charts).
**Tech:** Scala, Apache Spark, Apache Kafka, Spark NLP, OpenSearch, Streamlit

#### 📄 [CV Analysis RAG System](https://github.com/OppoTrainCommunity/RAG-Retrieval-basedon-chuncking)
A retrieval-augmented generation system for recruiting workflows: batch CV upload with AI-driven metadata extraction, a chat interface over the CV database using hybrid vector + BM25 search (merged via Reciprocal Rank Fusion) with source citations, and a job-matching pipeline that shortlists candidates by embedding similarity before an LLM re-ranks the top matches with scores, strengths, and gaps.
**Tech:** Python, Streamlit, LangChain, ChromaDB, Sentence-Transformers, OpenRouter API
